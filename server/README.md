# P&P 03 | APP Server Side

## Guide

### Created with Express 
This server side is created with Express, has a MongoDB database, JWT for authentication, and runs with:

npm run dev

### Installed Dependencies
- Express 5.3.0
- BcryptJS 3.0.3
- JSON Web Token 9.0.3
- Mongoose 9.13.1
- Cors 2.8.6
- Dot ENV 18.0.10
- Nodemon 3.1.14
- Path 0.12.7
